# PBS Mobile Android v1.0.0
WebView untuk URL Google Apps Script PBS. Sumber dan Android build dikompilasi oleh GitHub Actions.
Target: Android 8+ (minSdk 26); debug APK ditujukan untuk penggunaan internal.
Lokasi APK: Actions > Build PBS Mobile APK > Artifacts > PBS_Mobile_v1.0.0_APK.
Ikon adalah rekonstruksi grafis PBS, bukan salinan master logo resmi.
Google Login di dalam WebView mungkin dibatasi kebijakan Google; browser eksternal tidak berbagi sesi ke WebView.
