# PBS Galian Field Android v1.2.6

Android WebView companion for Node.js PBS GALIAN v1.2.6. UI feed Aktivitas is delivered by Node.js server; Android native code remains v1.2.5 for GPS, camera and multi-photo support. Refresh after updating server. Debug signing may prevent in-place install over an older debug APK signed with another key. Sync all offline data before any uninstall. Admin / Project Control see Aktivitas, not Waspang or Jointer.
